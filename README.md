# FatBoy Unpack
An [OpenGameInstaller](https://github.com/Nat3z/OpenGameInstaller) addon that adds support for FitGirl's Repacks.

# Installation
Ensure that Git is installed and Bun is installed.

Go to `Settings > General` and add to the addons field:
```
https://gitlab.com/nat3z/fatboy-unpack
```
Once that's done, press "Install All" and **wait a few minutes for FatBoy to scrape all of the game listings on FitGirl.**
You will know when it's ready when you see in the bottom right "FatBoy Repack installed"

# FatBoy Unpack
An [OpenGameInstaller](https://github.com/Nat3z/OpenGameInstaller) addon that adds support for FitGirl's Repacks.

## About this fork

This is ShockStruck's fork of [fat-addons/fatboy-unpack](https://gitlab.com/fat-addons/fatboy-unpack). The original code and its authorship belong to Nat3z / Fat-Addons; this fork carries changes that have not yet landed upstream.

Upstream is MIT-licensed (see `LICENSE`, "Copyright (c) 2024 Nat3z"). This fork keeps that licence unchanged and keeps the original attribution.

# Installation
Ensure that Git is installed and Bun is installed.

Go to `Settings > General` and add to the addons field:
```
https://github.com/shockstruck/fatboy-unpack
```
Once that's done, press "Install All" and **wait a few minutes for FatBoy to scrape all of the game listings on FitGirl.**
You will know when it's ready when you see in the bottom right "FatBoy Unpack installed."

Press "Restart Addons Server" and enjoy!
